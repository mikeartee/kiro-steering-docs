# AGENTS.md

Project memory for AI coding agents working in this repository.

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues (`mikeartee/kiro-steering-docs`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default six-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `tracking`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Ship style

Pull request: feature branch, PR with `Closes #<issue>`, human merges. See `docs/agents/ship-style.md`.

### Project board

GitHub Projects v2 board "kiro-steering-docs" (<https://github.com/users/mikeartee/projects/12>). See `docs/agents/project-board.md`.
